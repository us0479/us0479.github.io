  3. BankWatch DB 설계와 직접 구현: 진행 예정
직접 개발 준비

BankWatch

모바일뱅킹 계정 이상접속 탐지 및 사고 대응 관리

가상 고객의 접속 기록에서 이상 징후를 탐지하고, 경보의 근거와 사건 대응 이력을 관리하는 프로젝트입니다.

  • 구현 목표: 접속 로그 입력, 이상접속 탐지, 경보와 근거 조회
  • 업무 흐름: 담당자 배정, 가상 계정 조치, 처리 이력 관리
  • 학습 목표: PostgreSQL 설계, SQL, 트랜잭션과 동시성 검증

문서·소스·시연 링크는 직접 개발을 진행하며 추가할 예정입니다.

현재 페이지는 프로젝트 소개용 정적 홈페이지입니다. 실제 데이터베이스 기능은 아직 연결하지 않았습니다.
